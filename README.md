# todo-app-handson

タスク管理アプリケーションのサンプルハンズオンリポジトリ。

## 概要

シンプルなクライアントサイドのタスク管理アプリです。ブラウザのみで動作し、データは LocalStorage に保存されます。

## 技術スタック

- HTML
- CSS
- JavaScript
- LocalStorage

## 使い方

1. リポジトリをクローンまたは ZIP をダウンロード
2. ブラウザで index.html を開く
3. タスクの追加・編集・削除・完了が可能です。データはローカルのブラウザに保存されます。
